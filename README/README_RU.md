# WHERE-IS-SNI — Русский

> Набор доменов и скрипт оценки для поиска оптимального SNI для протокола REALITY.

---

## Введение

`WHERE-IS-SNI` предоставляет тщательно отобранный пул из доменов-кандидатов и Bash-скрипт для оценки, помогающий найти оптимальный SNI для протокола Xray REALITY.

## Файлы

| Файл | Описание |
|------|----------|
| `domains.txt` | Домены-кандидаты, охватывающих различные регионы и отрасли |
| `sni-finder.sh` | Скрипт автотестирования: случайный выбор, проверка, оценка, вывод JSON |
| `sni-finder-run.sh` | Скрипт установки и запуска в одну строку |
| `.gitignore` | Игнорирование локальных файлов конфигурации |

## Использование

**Запуск одной командой (случайные 15 доменов):**
```bash
bash <(curl -sL https://raw.githubusercontent.com/zsigoio/WHERE-IS-SNI/main/sni-finder-run.sh)
```

**Тестирование конкретных доменов:**
```bash
bash <(curl -sL https://raw.githubusercontent.com/zsigoio/WHERE-IS-SNI/main/sni-finder-run.sh) shopee.vn tiki.vn sendo.vn
```

Или клонирование локально:
```bash
# 1. Клонировать на ваш Linux-сервер
git clone https://github.com/zsigoio/WHERE-IS-SNI.git
cd WHERE-IS-SNI

# 2. Сделать исполняемым
chmod +x sni-finder.sh

# 3. Запустить напрямую (случайные 15 доменов)
bash sni-finder.sh

# 4. Тестировать конкретные домены
bash sni-finder.sh www.samsung.com www.sony.com www.intel.com

# 5. Указать размер выборки
bash sni-finder.sh -n 5

# 6. Пользовательский таймаут (секунды)
bash sni-finder.sh -t 3

# 7. Пользовательский файл списка доменов
bash sni-finder.sh -l my-domains.txt

# 8. Вывод в файл
bash sni-finder.sh -o result.json

# 9. Автоприменение лучшего SNI, пропустить меню
bash sni-finder.sh -y

# 10. Только JSON, без меню
bash sni-finder.sh --no-menu

# 11. Указать путь к конфигурации Xray
bash sni-finder.sh -y --xray-config /etc/xray/config.json

# 12. Подробный прогресс
bash sni-finder.sh -v

# 13. Комбинировать опции
bash sni-finder.sh -n 8 -t 4 -o result.json -v

# 14. Конкретные домены + автоприменение
bash sni-finder.sh -y www.cloudflare.com www.fastly.com
```

## Интерактивное меню

После тестирования появляются четыре опции:

```
 0) Выход
 1) Повторное тестирование с новыми случайными доменами
 2) Применить лучший SNI к конфигурации Xray и перезапустить
 3) Просмотр доменов по странам
```

- **0** — Выход
- **1** — Выбрать новые случайные домены и перетестировать (или перетестировать те же домены в режиме указания)
- **2** — Записать лучший SNI в конфигурацию Xray (автоматическое резервное копирование) и перезапустить службу
- **3** — Просмотр результатов тестирования, сгруппированных по странам (GeoIP через ip.im)

## Система оценки

Цель должна согласовать TLS 1.3, ALPN h2 и X25519 или X25519MLKEM768, а сертификат должен быть действителен для указанного SNI. Адреса Cloudflare и непубличные адреса исключаются. Команда с `--all --no-menu -o audit.json` сохраняет результаты и причины отказов для всех доменов.

## Зависимости

Требуются Go 1.25+, системное хранилище CA и Bash. Загрузчику также нужен curl.
